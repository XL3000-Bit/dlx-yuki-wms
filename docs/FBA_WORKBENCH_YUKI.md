# FBA 工作台衔接改进

本轮继续完善现有 YUKI 的 FBA 与出库流程，未直接移植 GreaterWMS 源码。

## 本轮改动

- FBA 明细已有 Picking、BOL 时，快捷按钮打开对应标签，可查看与下载单据；已有出库单时跳到出库工作台并定位该单。
- 预约保存改用 `PATCH /outbounds/{id}/schedule`，只提交预约、承运商、司机、车辆及备注字段，不再用整单更新提交客户等身份字段。
- 同一明细中的创建、生成、预约操作增加进行中保护；已完成或取消的出库单禁用预约入口。
- 批量操作与汇总统一使用当前页选中记录，改变筛选、排序或分页时清除选择；加载期间禁止执行批量操作。
- 批量响应显示逐条 FBA ID、成功/跳过/失败及原因；请求异常提示刷新核对后再重试。
- 单据、预约和批量操作完成后刷新关联工作台缓存。

## 验证

- TypeScript 检查通过，Vite 生产构建通过；仍有既有 Ant Design 分块体积提示。
- `test_fba_workbench.py`、`test_business_time.py`、`test_outbound.py` 共 20 项测试通过，运行使用测试内存数据库。Pytest 缓存目录存在写入权限提示，不影响测试结果。
- 本轮浏览器尝试访问 `http://localhost:5173/fba` 返回连接拒绝，本地前后端服务未监听，未完成页面点击验收。
- 未部署远程环境。

## 页面验收路径

1. 启动本地服务后进入 FBA 工作台，打开已有 Picking、BOL 和出库单的记录，分别验证三个快捷入口。
2. 在测试记录修改预约，核对客户、仓库和 FBA 关联仍保持原值。
3. 勾选当前页记录，对照下方汇总；切换页码或筛选，确认选择清空。
4. 使用测试记录执行批量操作，核对结果明细中的成功、跳过、失败和原因。

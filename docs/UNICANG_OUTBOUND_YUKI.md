# Unicang 出库学习与 YUKI 实现

日期：2026-09-09。参考用户已登录的 https://admin.unicanginc.com/admin/v2/outbounds ，结合仓库端 Ocean Inbound 与 BOL 页面。仅查看页面、展开记录和打开后取消创建表单，未提交参考系统的业务变更。

## 观察到的流程

管理端包含三个独立区域：出库单、全局 BOL、剩余 BOL。展开一个出库单不会把全局 BOL 列表自动变成该单明细。三个区域分别提供筛选、分页、字段配置、选择和数量合计。

出库单区承载预约、承运商、车型、目的地与状态；关联 BOL 明细提供箱数、重量、体积、出库及剩余托数。Ready To Ship、Hold、出库状态是不同维度；观察到 Ready 为 Yes 的取消或海关 Hold 记录，不能把一个标记当作全部可出库条件。

创建表单包含出库类型、配送方式、车型、承运商、提货参考、计划提货时间、送仓预约、预约托数、ISA 和送货参考，并要求选择关联 BOL，支持拖入关联区域。Actions 中有装货、预约导出、打印、合并、重定向、送货预约和 POD 等入口；本次未执行，完整业务规则未知。

源系统状态包括 New、Confirmed、Cargo Loaded、Partial Ship、Fully Ship、Exception、Canceled。YUKI 保留现有八阶段状态和库存规则，不直接替换成源系统枚举。

## 已实现

| 范围 | YUKI 行为 |
| --- | --- |
| 独立 Cargo BOL | 入库、FBA 和指定历史来源拥有稳定货物标识；出库分配关联 Cargo BOL |
| 三个独立区域 | 出库单、Cargo BOL、剩余 Cargo BOL 分别筛选、分页、选中、配置列和导出 |
| 明细与汇总 | 查看货物来源、分配出库单、已完成与待完成数量；显示当前页和选中数量汇总 |
| 创建并分配 | 创建出库时选择或拖入 Cargo BOL，校验同仓同客户，整笔事务提交 |
| FBA 约束 | 一次分配限制同一 FBA shipment，兼容多库存批次；不重复预留 |
| 导入关联 | 匹配客户、承运商；未知客户或客户不符报错，未知承运商提示警告 |
| 页面打磨 | 调整宽表、列省略、PO 悬浮内容、明细布局、创建选择器及桌面/笔记本显示 |

分配采用剩余可分配数量；一次选择最多 100 个 Cargo BOL，导出最多 10,000 条。历史货物标识用于追溯，不自动变成可分配库存。源系统尚未核实的合并、重定向等动作未伪装成可用功能。

服务端锁定出库单、货物和相关库存，整组验证失败时回滚。标准入库货物从可用量转为已分配量，FBA 沿用已有预留；完成出库扣减，取消释放未完成数量。已取消状态不计为已发货。

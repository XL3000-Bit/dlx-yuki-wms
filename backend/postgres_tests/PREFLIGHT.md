# 迁移前只读核实（尚未运行验证）

本入口只核实连接身份及必要权限，不证明隔离成立，不运行迁移、测试或资料初始化。不依赖项目初始化，也不要求 alembic_version 或测试资料存在。导入模块不建立连接。

## 独立入口

以下命令仅供后续获准连接时执行，本次交付未执行：

```powershell
& 'C:\Users\XL\dlx-yuki-wms\backend\.venv\Scripts\python.exe' 'C:\Users\XL\dlx-yuki-wms\backend\postgres_tests\preflight.py'
```

- `PHASE113_PG_DSN`：管理员在本地提供的显式 PostgreSQL 目标及合法认证，仅供进程使用。不得提交到仓库或粘贴到聊天中。
- `PHASE113_PG_MANIFEST`：后续独立测试使用的完整清单绝对路径；迁移前入口不读取它，也不要求它提前完成。
- 缺少 DSN 在连接前拒绝。必须显式指定单一 IP 地址、端口、数据库和角色；不猜测维护数据库，不因目标不存在而替换目标。
- 沿用 guard.py 的连接参数限制：拒绝 hostaddr、service、servicefile、options，以及非空的 PGOPTIONS、PGSERVICE、PGSERVICEFILE、PGHOSTADDR、PGHOST、PGPORT、PGDATABASE、PGUSER 环境覆盖。现有测试防护代码未作修改。
- 连接超时 5 秒，只建立一次连接；只读事务的查询超时 5 秒、锁等待超时 5 秒。最终关闭连接，不提交写事务。
- 输出 ASCII JSON，包括实际身份及必要权限；错误只输出受限诊断字段，不输出原始异常、连接串或密码。未知错误保持未分类，不推断原因。
- 连接成功且目标匹配仍返回 `isolation_status: NOT_VERIFIED`。权限查询结果也不是全部迁移权限已经具备的证明。

## 清单与证据分工

`manifest.template.json` 对应现有测试 guard 的字段。模板故意含空值和 false，不能作为有效清单。将后续真实清单及证据存放在仓库外的专用目录，不保存凭据；不要把模板直接当成隔离证明。

| 内容 | 取得方式及责任 |
| --- | --- |
| identity 的 database、role、address、port、database_oid、server_version_num | 获准连接后由本入口只读查询；与管理员指定的目标核对。服务器版本和必要权限另行输出。 |
| database_ownership | 管理员确认专用目标的业务归属、无真实业务数据及允许的写入范围；工程补充实际目标与使用方核实。数据库 owner 角色不等于业务授权。 |
| storage_isolation | 工程核实测试及应用配置、实际附件目录、数据库目标和无默认业务数据库回退路径；保留不含敏感值的证据。 |
| external_effects_disabled | 工程核实提醒、通知、任务及外部调用的禁用或测试替代边界，包含迁移、资料准备及测试所经过的路径。无法证明则不得写入。 |
| synthetic_fixtures | 目标隔离及写入获准后，仅准备合成资料；记录来源、范围和实际标识，不复制真实业务数据。 |
| reviewer、reviewed_at、exclusive_database | 在真实证据完成后记录实际审阅人、时间及独占用途结论；不可用确认开关替代证据。 |
| evidence 中 path、sha256 | 工程对真实证据文件记录绝对路径，并计算实际 SHA-256。摘要仅绑定文件内容，不能证明其陈述正确或隔离成立。模板不生成假摘要。 |
| migration_revision、fixtures | 工程在授权迁移和合成资料准备后核实；版本必须满足现有 guard，三个 Load 标识必须不同，其余标识应指向对应的真实合成资料。 |

需要用户或管理员提供的最少信息：有效认证仅在本地提供；指定专用目标并确认其归属、独占测试用途和允许写入范围。实际地址身份、存储配置、调用链及摘要等工程可核实内容不要求用户重复调查。若目标尚不存在，停止本入口的连接准备，另行处理创建授权与准备，不猜测其他连接目标。

## 顺序与防护边界

1. 获准后执行只读身份核实，并完成专用目标、存储及外部副作用隔离核实。连接成功本身不能进入下一步。
2. 获授权后对已核实专用目标执行项目迁移；迁移配置必须显式指向同一目标。本入口不执行迁移。
3. 在同一专用目标准备最小合成资料，核实准备过程的存储及外部副作用边界。
4. 完成清单、真实证据及摘要；确认迁移目标、资料目标、测试目标一致。
5. 获准后运行现有独立测试入口：

```powershell
& 'C:\Users\XL\dlx-yuki-wms\backend\.venv\Scripts\python.exe' 'C:\Users\XL\dlx-yuki-wms\backend\postgres_tests\run.py'
```

迁移前入口不检查迁移版本或资料，因此不存在必须先迁移才能核实身份的循环。现有 run.py 的完整迁移、资料和隔离防护保持不变；不得用迁移前入口绕过它。

后续准备会产生结构和合成资料；集成测试会尝试约束相关写入，部分事务回滚，但并发场景的提交和既有派发路径相关记录可能保留。不能承诺全套测试零写入或全部回滚。保留专用数据库、附件目录、清单及证据供复核；清理另行授权。

真实登录令牌链路、GET 的外部调用及序列变化不属于已有断言的完整覆盖，部分数量比较使用合成输入。这些是验收范围限制；外部副作用隔离证据缺失则是运行阻塞，不能以覆盖限制为由放行。
